# Acessibilidade

Checklist mínimo para cada alteração visual:
- controles com nome acessível e foco visível;
- imagens informativas com texto alternativo;
- formulários com labels;
- navegação utilizável por teclado;
- mensagens de erro compreensíveis;
- contraste suficiente;
- layout funcional com zoom e telas pequenas.

Não remover atributos ARIA ou labels sem substituição equivalente.
